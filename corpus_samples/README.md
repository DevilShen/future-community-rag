# 虚构示例语料（不参与自动入库）

⚠️ **本目录下所有文档均为虚构示例，不是真实政策、标准、合同或案例。**
文中机构名、条款、数据、联系方式均为编写，**不可作为任何决策依据**。

## 为什么单独放这里

本项目的语料是「未来社区 / 智慧物业」这类**政策与验收标准**。合成的示例文档若与真实
PDF 混在同一个向量库、同一个来源列表里，演示时极易被误读成真实条文——我们的答案还带
`[1][2]` 引用标注和匹配度，看起来非常像在引权威依据。所以示例语料**独立存放，
不自动入库**。

## 目录会把示例入库吗

不会。入库管道只扫描 `corpus/` 下的五个分类子目录
（见 `config.CATEGORIES` 与 `ingest.collect_files`），本目录在 `corpus/` 之外，
`python ingest.py` 不会读到它。

## 什么时候用它

| 场景 | 做法 |
|---|---|
| 只想演示「格式长什么样」 | 直接阅读本目录的 md 文件 |
| 空库演示，还没有真实语料 | 把需要的分类**手动**拷进 `corpus/` 对应目录，入库，演示完再删 |
| 已有真实语料 | 不要拷入。示例的价值只剩「格式模板」 |

手动拷入并演示（示例，仅用于空库场景）：

```bash
# 拷入五个分类
cp corpus_samples/01_行业标准/*.md corpus/01_行业标准/
cp corpus_samples/02_交付流程/*.md corpus/02_交付流程/
cp corpus_samples/03_操作手册/*.md corpus/03_操作手册/
cp corpus_samples/04_交付文档/*.md corpus/04_交付文档/
cp corpus_samples/05_过往案例/*.md corpus/05_过往案例/

python ingest.py --rebuild          # 重建

# ⚠️ 演示结束后务必清掉，并按重建，避免示例长期混在真实库里
rm corpus/0*/*示例_*.md
python ingest.py --rebuild
```

## 每份示例的内容

| 文件 | 分类 | 用途 |
|---|---|---|
| `01_行业标准/示例_未来社区建设评价指标口径.md` | 行业标准 | 指标分值与达标口径，演示「数值类问答」 |
| `02_交付流程/示例_未来社区项目交付实施流程.md` | 交付流程 | 分阶段流程与时限，演示「流程类问答」 |
| `03_操作手册/示例_智慧物业平台工单操作手册.md` | 操作手册 | 分步操作说明，演示「操作类问答」 |
| `04_交付文档/示例_项目交付验收资料清单.md` | 交付文档 | 资料清单与归档要求，演示「清单类问答」 |
| `05_过往案例/示例_某社区数字化验收整改案例.md` | 过往案例 | 含**故意植入的假手机号/邮箱**，用于演示脱敏 |

> `05_过往案例` 里的手机号 `13800138000`、邮箱、门牌号是**故意写的假数据**，
> 用来验证入库管道的脱敏环节真的生效（入库时应看到「脱敏命中」不为「无」）。
