# 智慧物业平台 · 工单管理操作手册（虚构示例）

> ⚠️ **本文档为虚构示例，用于演示知识库入库与问答链路，不是真实产品的操作手册。**
> 文中的菜单路径、按钮名称、字段名均为编写，**不可作为实际操作依据**。

## 一、适用范围

本手册适用于物业客服、工程维修、项目经理三类角色的日常工单处理。
各角色的可见菜单不同，请以实际账号权限为准。

## 二、角色与权限

| 角色 | 可执行操作 |
|---|---|
| 客服 | 创建工单、派单、回访、查询 |
| 工程维修 | 接单、处理、填写处理结果、申请转派 |
| 项目经理 | 全部操作 + 工单统计、超时工单审批 |

## 三、创建工单

**操作路径**：工作台 → 工单管理 → 新建工单

1. 点击「新建工单」按钮，打开新建表单；
2. 填写必填项（带 `*` 号）：
   - **报修人**：从业主档案中选择，不要手输，否则无法关联历史记录；
   - **联系电话**：选择业主后自动带出，如为空需先在业主档案中补录；
   - **所属楼栋 / 房号**：选择楼栋后房号下拉会自动过滤；
   - **问题分类**：从字典中选择，分为「水电」「电梯」「门禁」「公共设施」「其他」；
   - **问题描述**：不少于 10 个字，建议附现场照片；
3. 上传现场照片（可选，最多 9 张，单张不超过 5MB）；
4. 点击「提交」，工单状态为**待派单**。

> **常见问题**：报修人下拉框搜不到业主？
> 检查该业主档案状态是否为「正常」。已迁出的业主不会出现在下拉列表中。

## 四、派单

**操作路径**：工单详情 → 派单

1. 在待派单列表点击工单，进入详情页；
2. 点击「派单」，选择处理人（可按技能标签筛选，如「电工」「电梯维保」）；
3. 设置**要求完成时间**：一般工单默认 24 小时，紧急工单默认 4 小时；
4. 点击「确认派单」，工单状态变为**处理中**，处理人会收到站内通知。

**批量派单**：在列表页勾选多条工单 → 点击「批量派单」→ 选择处理人 → 确认。
批量派单不区分紧急程度，请谨慎使用。

## 五、处理与完成

**操作路径**：我的工单 → 待处理 → 选择工单

1. 点击「接单」，状态变为**已接单**；
2. 到场处理后，填写「处理结果」，必须填写**实际耗时**与**材料消耗**；
3. 上传处理后照片（建议与报修照片同角度，便于对比）；
4. 点击「完成」，工单状态变为**待回访**。

**转派**：如非本专业技能范围，点击「申请转派」，选择转派对象并说明理由，
需项目经理审批后生效。

## 六、回访

**操作路径**：待回访列表 → 选择工单 → 回访

1. 联系报修人确认问题是否解决；
2. 选择满意度（非常满意 / 满意 / 一般 / 不满意）；
3. 如选择「不满意」，必须填写原因，工单将重新打开并回到派单环节；
4. 点击「提交回访」，工单状态变为**已关闭**。

## 七、超时工单处理

系统每 **30 分钟**扫描一次，超过要求完成时间未完成的工单标记为**超时**。

- 超时工单在列表中以红色高亮，并推送提醒给处理人与项目经理；
- 超时 **2 小时**未处理的，自动上报项目经理；
- 项目经理可在「超时工单」页面进行督办或改派。

## 八、常用查询

- 按状态查：工单管理 → 状态筛选 → 选择「处理中」
- 按楼栋查：工单管理 → 高级筛选 → 输入楼栋号
- 按时间查：工单管理 → 高级筛选 → 选择报修时间区间
